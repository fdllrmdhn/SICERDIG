# SICERDIG – Platform Literasi Digital

A web learning platform that builds digital literacy for secondary-school students, part of the Lingkasa Edu project. Students learn to read critically, recognise hoaxes, stay safe online, and communicate respectfully, with progress rewarded through a gamified XP system.

## Features

- **Modul Literasi**: critical reading, text structure, and reflection quizzes
- **Uji Hoaks / Cek Fakta**: telling facts from opinions and checking news articles
- **Zona Keamanan Digital**: online safety and phishing awareness
- **Komentarmu Cerminanmu**: polite and constructive online communication
- **Empat Pilar Literasi Digital** and social-media data analysis pages
- **Gamification**: XP points and badges across activities
- **DIGI Chatbot**: an AI assistant that answers students' questions (via OpenRouter)
- Short educational videos on digital ethics, culture, and cyberbullying

## Running locally

No build step is needed. Clone the repository and open `index.html` in a browser.

### Enabling the chatbot

The API key has been removed from the source. To use the chatbot, create a free key at [openrouter.ai](https://openrouter.ai) and replace `YOUR_OPENROUTER_API_KEY` in `DigiChatBot.html`. Do not commit a real key to a public repository.

## Tech stack

HTML, JavaScript, Tailwind CSS, AOS, Font Awesome, OpenRouter API
